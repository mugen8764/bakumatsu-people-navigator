# 次の情報拡充計画：開国交渉から対外衝突へ

作成日: 2026-09-25。基準: `baa880c` / contentVersion `1.0.63`。
本書は外交編A〜Cの計画と進行記録。各公開単位の検証結果を末尾に追記する。

## 現状の評価と優先順位

現在は67名・16時点・個別事件11件・転換点8件・背景解説19項目・史料肖像18点。個別事件は1858〜1868年に分布し、京都の政変、薩長提携、政権交替、江戸開城が充実した。

次回は「開国交渉から対外衝突へ」を優先する。日米和親条約、生麦事件、薩英戦争、四国艦隊の下関攻撃には年単位の説明があるが、個別事件として役割を分けて読む画面がない。1858年の通商条約には日本側署名者の名前が本文にある一方、人物カードがない。既存のペリー、ハリス、阿部、井伊、久光、小松、海江田、サトウ、高杉、伊藤、井上馨を活かして、この空白を埋める。

その次は「北越から箱館へ」、続いて「土佐の藩内政治と支援者・生活」の順を候補とする。今回の詳細計画と公開単位は、以下の外交編A〜Cに限定する。

## 既存の枠組みで作る内容

- 人物には読み・別名・その時点の名前と役割・関係・場所・事件・根拠を揃える。確認できる活動期間だけを表示する。
- 個別事件は既存16時点の内側に置く。Aは `1854-treaty` と `1858-ansei`、Bは `1862-bunkyu` と `1863-joi`、Cは `1864-kinmon` を使う。既存URLと時点選択を維持する。
- 事件カードは「現場」「意思決定」「背景」を区別し、原則5〜7名、最大9名に収める。公使・通訳・軍人・商人を役割欄で区別する。
- 関係線は交渉、指揮、協力など、直接の根拠があるものだけを登録する。同じ英国側・薩摩側というだけでは個人同士を結ばない。
- 地図は横浜、下田、箱館、生麦、鹿児島、下関など既存地点を使い、事件と人物の移動をつなぐ。地点追加が必要になれば、実在位置の根拠を確認して個別に判断する。
- 背景解説は「全権」「批准」「領事裁判権」「関税自主権」の4候補。既存の勅許・開港・通詞・外国人居留地と重複させず、該当人物や事件の近くから開く。
- 転換点は伊藤・井上馨の留学から帰国前後を1〜2件の調査候補とする。隣接時点の状態と根拠を満たす場合に採用する。既存の高杉の比較へも接続する。
- 肖像はペリー・ハリス・阿部・井伊など、この範囲で繰り返し登場する既存人物から3〜4点を調査する。本人への帰属、年代、転載条件、初回読込容量を確認して採用する。
