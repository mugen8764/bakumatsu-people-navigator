## 検証方針

公開用 `dist/` を構築し、データ契約・年別状態・検索・URLの検査とブラウザー検査を実行する。新しい2事件は検索、人物、再読込、事件への復帰、地図、履歴移動を通して確認する。320pxの両テーマ、キーボード、拡大文字での見出し位置、WCAG A/AAを検査する。用語の重複、不明参照、出典のないverified、不正な関係方向を拒否する。

肖像と人物数に伴う画像差分は目視で確認してから更新する。地図の既存画像検査、初期レイアウトのずれ、転送量上限は弱めない。出典URLの通信障害と明確なリンク切れは分けて報告する。本番のファイル照合と公開画面での操作まで確認する。第三者による利用者評価は今回の自動検査・開発時の操作確認には含めない。

公開前の結果：`npm run build:site`、`STATIC_SITE_ROOT=dist` での `npm test`（データ・ドメイン64件、Chromium87件）が成功。人物画面4枚の画像差分を確認して更新し、地図6枚の画像は変更していない。3事件×320px・1280px×ライト・ダークの実操作で、見出しの隠れ・横溢れ・JavaScript例外はなかった。初回読み込みは約516KB。出典リンク234件は正常232件、警告2件、明確なリンク切れ0件だった。警告は既存の `kwansei_kawaji_letter` の通信失敗と、英国ナショナル・ポートレート・ギャラリーの `npg_parkes_lifespan` のHTTP 403。後者の本文は調査時に確認しており、到達性の再検査だけを未確認として扱う。
