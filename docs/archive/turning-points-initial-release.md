# 人物の転換点と役職解説：実装・検証記録

> 過去の計画・作業記録です。件数・検査結果・「次の作業」は記録当時の内容で、現行の実装指示ではありません。[現在の手順](../README.md)を参照してください。

対象は contentVersion 1.0.62。西郷・木戸・慶喜の3件の比較と、老中・勘定奉行・藩主・家老の解説を追加した。

## 表示と操作

- 前後の名前・所属・役職と、行動・関係の変化を一つの欄で読める。
- スマートフォンでは前後を縦に、十分な幅がある詳細欄では横に並べる。
- 対象年代の「人物・勢力と時点の変化」から比較へ移れる。ほかの年代でも対象人物の「転換点を比べる」から移れる。
- 人物の役職ボタン、または「役職を知る」から説明を開閉できる。

## 編集上の境界

比較は `data/people.json` の `turningPoints` に個別に記述する。文章の差分から立場・動機・関係の変化を推測しない。隣接する登録時点を比較し、対象人物の活動範囲内に限る。比較の根拠と、元の時点別情報の根拠は分けて表示する。

年内の複数の出来事を扱う時点もあるため、比較は各年の概要であり、事件当日の状態の比較とはしない。大政奉還の比較では王政復古との区別を明記する。比較未収録の人物や年代に「変化なし」とは表示しない。

役職解説は表示中の役職名に該当語がある場合に付く。「前藩主」の「前」は残し、解説の表示をもって現職とは扱わない。役職が確定しない人物に新たな肩書きを与えない。

## 自動検査で確認する範囲

- 3件の比較の年代・活動範囲・出典参照、生成データの往復一致。
- 年代往復、URL再読込、履歴で戻る、事件詳細への復帰。
- 4役職の解説開閉とキーボード操作。
- 320pxのライト・ダーク、WCAG A/AA、ページの横溢れ。
- 従来の表示・地図・検索・公開検査、550KB未満の初回リソース予算。

## 実装時の確認記録

2026-09-24、生成した `dist/` でデータ検査73件とChromiumの画面検査101件を確認した。既存の画像スナップショットは更新していない。3人の比較、役職4項目、320pxのライト・ダーク、キーボードとURL・履歴の往復を含む。比較欄と役職解説はスクリーンショットでも確認した。

追加・再確認した出典URLは8件とも到達できた。出典本文で確認した箇所と確認日は正本JSONに記録した。初回読み込みの非圧縮リソース合計は546,333バイトで、550,000バイトの既存上限内。配信時に重複する文字列を共有し、復元後のデータと校正状態が従来どおり一致することを検査している。
