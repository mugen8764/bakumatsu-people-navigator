## 記録の読み方

- 過去の「未着手」「次回候補」は現在のバックログではありません。採用状況は正本JSON、変更履歴、現行ガイドで確認します。
- 出典を読めた範囲、異説、採用しなかった主張は、再編集の判断材料として残します。現在の校正状態は正本データが基準です。
- 検査結果はその版に対する実績です。現在の必須検査と公開方法は [開発・運用手順](../maintenance.md) に従います。
- `browser-data-encoding.md` は現行実装の設計資料として [一つ上の階層](../browser-data-encoding.md) に残しています。
