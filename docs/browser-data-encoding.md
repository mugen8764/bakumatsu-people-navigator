# ブラウザー用データの圧縮

正本は引き続き `data/*.json`、互換JSONは `data.json`。`data.js` は `scripts/build-data.cjs` が生成し、読み込み時に同じ内容の `window.BM_DATA` を同期的に復元する。生成物を直接編集しない。

2026年9月の外交編Bでは、従来のオブジェクト形状・重複文字列の共有だけでは初回読込の550,000バイト上限を超える。日本語の説明文にも繰り返しがあるため、JSON文字列全体へのLZW圧縮へ切り替える。アプリケーションコードのバンドル、非同期取得、外部の展開APIは追加しない。

圧縮辞書の初期値はJSON文字列に出現するUTF-16コード単位。262,144コード単位ごとに辞書をリセットする。辞書番号はASCIIを避け、サロゲート範囲を飛ばしたUnicodeスカラーとして保存する。番号の最大値は65,536 + 262,144未満なので、データが増えてもUnicodeの上限を超えない。復元後にまとめて `JSON.parse` するため、ブロック境界が文字やJSONトークンを分断しても内容は変わらない。

検査では公開JSON全体の一致、独立した可変オブジェクト、負数・配列・空値・`__proto__`、日本語・絵文字・単独サロゲート、BMP境界と複数ブロックを確認する。ブラウザーでは既存の3エンジン検査、初期レイアウトと容量上限を維持する。
