# ブラウザー用データの圧縮

正本は `data/*.json`、互換JSONは `data.json` です。`data.js` は [build-data.cjs](../scripts/build-data.cjs) が生成し、読み込み時に同じ内容の `window.BM_DATA` を同期的に復元します。生成物を直接編集しません。

## 採用している方式

2026年9月の外交編Bで、従来のオブジェクト形状・重複文字列の共有方式から、JSON文字列全体へのLZW圧縮へ切り替えました。説明文にも含まれる繰り返しを圧縮し、初回読み込み量の既存上限を維持するためです。アプリケーションコードのバンドル、非同期取得、外部の展開APIは使いません。

圧縮辞書の初期値はJSON文字列に出現するUTF-16コード単位です。262,144コード単位ごとに辞書をリセットします。辞書番号はASCIIを避け、サロゲート範囲を飛ばしたUnicodeスカラーとして保存します。辞書番号の最大値は65,536 + 262,144未満に収まり、保存時のオフセットを加えてもUnicodeの上限を超えません。

復元後に全ブロックを結合して `JSON.parse` するため、ブロック境界が文字やJSONトークンを分断しても内容は変わりません。これは配信ファイル内部の表現であり、HTTPの圧縮設定とは別です。

## 変更時の確認

[browser-encoding.test.cjs](../tests/data/browser-encoding.test.cjs) で、公開JSON全体の一致、独立した可変オブジェクト、負数・配列・空値・`__proto__`、日本語・絵文字・単独サロゲート、BMP境界と複数ブロックを確認します。

```sh
npm run build:data
npm test
npm run build:site
```

生成方式を変更した場合も、正本・互換JSON・復元後データの内容と校正状態を一致させます。ブラウザー3エンジン、初期レイアウト、初回読み込み量の確認方法は [開発・運用手順](maintenance.md) を参照してください。
