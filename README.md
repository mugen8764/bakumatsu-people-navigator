# 幕末人物・勢力ナビ 1853–1869

黒船来航から箱館戦争終結までを、人物・勢力・事件・場所の関係として読む静的ウェブサイトです。
特定の漫画・ドラマ・小説の情報は含めず、史実だけで構成しています。

## 収録内容

- 人物: 42名
- 勢力: 11
- 時点・主要事件: 16
- 人物関係: 79
- 勢力関係: 17
- 地点: 27

## 主な機能

- 1853〜1869年の時系列スライダーと自動再生
- 選択時点に応じた人物名・役職・所属の変更
- 本名、通称、変名、後年の名前、役職を含む横断検索
- 人物中心の時点別相関図
- 勢力ごとの目的・立場・構成人物・他勢力との関係
- 人物と事件の関連地を重ねた日本地図
- 原因・争点・結果をつないだ事件タイムライン
- URLハッシュによる表示状態の共有
- 出典・編集方針のページ

## 公開方法

依存関係を固定どおり導入し、公開用の `dist/` を生成してください。

```sh
npm ci
npm run build:site
```

`dist/index.html` がトップページです。`dist/` の内容だけを静的サイトホスティングへ配置してください。アプリケーション自体にバンドルや変換は行わず、開発用のテスト・スクリプト・依存パッケージを公開物から除外します。

例:

- Netlify Dropへ `dist/` またはそのZIPをアップロード
- Cloudflare PagesのDirect Upload
- GitHub Pagesの公開ディレクトリへ `dist/` の内容を配置

公開前に、生成データ、参照ファイル、セキュリティヘッダー、校正状態を確認してください。

```sh
npm run check:release
```

`_headers` はNetlifyとCloudflare Pages向けです。GitHub Pagesなど、このファイルを解釈しない配信先では同等のHTTPヘッダーをCDNまたはリバースプロキシ側で設定してください。

## データ編集

- `data/*.json`: 人物・勢力・時点・事件・関係・地点の正本データ
- `data.json`: 分割JSONから生成する互換データ
- `data.js`: 分割JSONから生成するブラウザ読み込み用データ
- `src/app.js`: 状態変更と画面描画をつなぐエントリーポイント
- `src/domain.js`: 時点別状態・関係・活動範囲のドメイン処理
- `src/renderers/`: 人物・勢力・相関図・事件などの画面描画
- `src/styles.css`: レイアウトと配色
- `map-data.js`: Natural Earth由来の低解像度地理形状を、このサイト用に投影・変換したSVGパス

人物の状態は `data/person-statuses.json` に追加します。表示期間には `startSceneId` と `endSceneId` を指定し、勢力などの参照には表示名ではなく安定IDを使います。

データ編集後は互換ファイルを再生成してください。

```sh
npm run build:data
```

## 注意

- 日付は、定着した旧暦日付と換算後の西暦日付を必要に応じて併記しています。
- 地図は主要地点の位置関係を示すもので、幕末期の藩境・支配範囲・全旅程を再現しません。
- 密約の動機など解釈が分かれる内容は、確認しやすい公的立場・行動・結果を中心に記述しています。
- 正式な研究・引用では、サイト内の出典リンクから原資料・専門文献を確認してください。
- 人物、時点別状態、勢力、関係、事件、地点には項目単位の出典と校正状態を登録しています。直接根拠を確定できない項目は、推測で補わず `needs_review` として公開画面にも明示します。

## 自動テスト

Node.js 20以降を使用します。初回のみ依存パッケージとChromiumを準備してください。

```sh
npm install
npx playwright install chromium
```

現行データと次期分割データ契約を検証する場合:

```sh
npm run validate:data
```

データ契約の詳細は `schema/README.md` を参照してください。

データ整合性テストだけを実行する場合:

```sh
npm run test:data
```

ブラウザE2Eと表示スナップショットを含む全テストを実行する場合:

```sh
npm test
```

意図した表示変更後に画像の基準を更新する場合:

```sh
npm run test:e2e:update
```

校正状態の件数を確認する場合:

```sh
npm run report:review
```

GitHub Actionsでは、プッシュとプルリクエストごとに `dist/` を生成し、その公開成果物に対してChromiumの全テスト、FirefoxとWebKitの主要操作テストを実行します。
登録済みの公式出典URLは週1回 `npm run check:links` で到達性を確認します。外部サイト側の一時障害を通常のプッシュ検査へ波及させないため、リンク検査は独立した定期ジョブです。

- `data/manifest.json` の `contentVersion` と `updated` を更新する
- 校正待ち項目とサイト上の注意書きを確認する
